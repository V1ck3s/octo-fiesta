# Octo-Fiesta

A Subsonic API proxy server that transparently integrates multiple music streaming providers as sources. When a song is not available in your local Navidrome library, it is automatically fetched from your configured provider, downloaded, and served to your Subsonic-compatible client. The downloaded song is then added to your library, making it available locally for future listens.

This is a fork of [V1ck3s/octo-fiesta](https://github.com/V1ck3s/octo-fiesta) that trims the provider list down to the ones that are actually reliable, and adds JioSaavn and YouTube as sources.

## Why "Octo-Fiesta"?

The name was randomly generated by GitHub when creating the original repository. It stuck.

## Features

- **Multi-Provider Architecture**: Pluggable music service system supporting multiple streaming providers
- **Transparent Proxy**: Acts as a middleware between Subsonic clients and your Navidrome server
- **Seamless Integration**: Automatically searches and streams music from your configured provider when not available locally
- **Automatic Downloads**: Songs are downloaded on-the-fly and cached for future use
- **External Playlist Support**: Search, discover, and download playlists with automatic M3U generation (Qobuz and Yandex)
- **Hi-Res Audio Support**: Up to 24-bit/192kHz FLAC quality (Qobuz)
- **Full Metadata Embedding**: Complete ID3 tags and embedded cover art
- **Synced Lyrics**: Time-synced lyrics for external tracks via [LRCLIB](https://lrclib.net) (OpenSubsonic `getLyricsBySongId`), shown on the very first listen and saved as `.lrc` sidecars for downloaded files
- **Organized Library**: Downloads saved in clean `Artist/Album/Track` folder structure

## Supported Music Providers

| Provider | Credentials Required | Max Quality | Playlist Support |
|----------|---------------------|-------------|------------------|
| [JioSaavn](https://www.jiosaavn.com/) | No | 320 kbps AAC | No |
| [Qobuz](https://www.qobuz.com/) | Yes | FLAC 24-bit/192kHz | Yes |
| [Yandex Music](https://music.yandex.ru) | Yes | FLAC 16-bit | Yes |
| YouTube (via [yt-dlp](https://github.com/yt-dlp/yt-dlp)) | No | ~128-256 kbps (source-dependent) | No |

Only one provider is active at a time, set via `MUSIC_SERVICE`. See the [Supported Music Providers](https://github.com/Shk2f/octo-fiesta-yt/wiki/Supported-Music-Providers) wiki page for details, including why SquidWTF and Deezer were dropped from this fork.

## Compatible Clients

Any Subsonic/OpenSubsonic client works for browsing and playback. The one thing that varies a lot between clients is **whether search actually reaches this server** — some clients build a local index and stop calling the server's search endpoint once that index is "complete," which means they'll never surface a song this proxy could fetch externally but hasn't downloaded yet. See the [Compatible Clients](https://github.com/Shk2f/octo-fiesta-yt/wiki/Compatible-Clients) wiki page for the full picture; short version:

| Platform | Recommended | Notes |
|----------|-------------|-------|
| **Desktop** | [Feishin](https://github.com/jeffvli/feishin) | Always queries the server live. Point `SERVER_URL` at this proxy, not Navidrome directly. |
| **iOS / CarPlay** | [play:Sub](https://apps.apple.com/us/app/play-sub-music-streamer/id955329386) | Thin client, always live search, strong CarPlay support. |
| **iOS / Android** | [Substreamer](https://substreamerapp.com/) | Works, but once its background library sync completes it stops calling server search entirely — pause the sync (Settings → Library & Data) if you need live external results. |

## Quick Start

### Requirements

- A running [Navidrome](https://www.navidrome.org/) server (or other Subsonic-compatible server)
- Docker and Docker Compose (recommended) or [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

### Docker Installation

Using the prebuilt image (fastest, updates automatically with a tool like [Watchtower](https://containrrr.dev/watchtower/)):

```bash
mkdir octo-fiesta && cd octo-fiesta
curl -O https://raw.githubusercontent.com/Shk2f/octo-fiesta-yt/dev/docker-compose.yml
curl -O https://raw.githubusercontent.com/Shk2f/octo-fiesta-yt/dev/.env.example
cp .env.example .env
nano .env  # Edit with your settings

docker compose up -d
```

Or build from source:

```bash
git clone https://github.com/Shk2f/octo-fiesta-yt.git
cd octo-fiesta-yt
cp .env.example .env
nano .env  # Edit with your settings

docker compose up -d --build
```

The proxy will be available at `http://localhost:5274`. Point your Subsonic client to this URL instead of your Navidrome server.

See the [Installation](https://github.com/Shk2f/octo-fiesta-yt/wiki/Installation) wiki page for detailed instructions including manual installation.

## Configuration

See the [Configuration](https://github.com/Shk2f/octo-fiesta-yt/wiki/Configuration) wiki page for all available settings.

### Getting Credentials

- **Qobuz**: see the [Configuration](https://github.com/Shk2f/octo-fiesta-yt/wiki/Configuration#qobuz) wiki page for how to get your User ID & Token.
- **Yandex**: credentials may be obtained by authorizing the official Yandex Music OAuth client [here](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d). After authorization the OAuth token appears in the address bar in the `#access_token=` fragment.
- **JioSaavn**: no credentials needed.
- **YouTube**: no credentials needed for public content; set `YOUTUBE_COOKIES_PATH` only if you need age-restricted/authenticated content.

```
│  Client         │◀────│   (Proxy)        │◀────│   Server        │
│  (Feishin)      │     │                  │     │                 │
└─────────────────┘     └────────┬─────────┘     └─────────────────┘
                                 │
                                 ▼
                        ┌─────────────────┐
                        │ Music Providers │
                        │  - JioSaavn     │
                        │  - Qobuz        │
                        │  - Yandex       │
                        │  - YouTube      │
                        └─────────────────┘
```

## Limitations

- **Playlist Search**: Streaming provider playlists appear in global search but may not show in the Playlists tab due to client-side filtering.
- **Playlist Display**: Due to Subsonic API limitations, playlists appear at the end of the album list with a music note icon. See [Playlists](https://github.com/Shk2f/octo-fiesta-yt/wiki/Playlists) for details.
- **Token Expiration**: Provider authentication tokens expire and need periodic refresh.
- **Client-side search caching**: some clients (see [Compatible Clients](https://github.com/Shk2f/octo-fiesta-yt/wiki/Compatible-Clients)) stop calling this server's search once their local library index is complete, which means newly-fetchable external songs won't surface until you disable/pause that client's local sync.
